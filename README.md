# 쑨플레이 3D

의자 컬링 · 치킨 드라이브 · 맥주 잘 따르기 · 파스타 만들기 · 달고나 뽑기. Three.js 기반 브라우저 게임 5종입니다.

https://ssunplay-arcade.vercel.app/

## 실행 및 검사

Node.js 24에서 npm install, npm run build, npm run dev. 개발 서버는 http://localhost:4173 입니다.

npm test: 엔진 검사 23개와 원본 자동차 수치 50개 차등 검사를 실행합니다. npm run check: 문법 검사. npx playwright install chromium 후 서버를 켜고 npm run test:browser: 데스크톱·모바일 조작 검사를 실행합니다. npm run build 후 npm run test:overflow는 자체 로컬 서버와 headless 브라우저로 맥주 넘침·조작부·감점을 검사합니다. BASE_URL을 지정하면 해당 배포를 검사합니다.

## 게임과 조작

- /game/curling/ : 비틀거리는 동료에게 의자를 스와이프해서 보내세요. 대기 중에도 무작위로 무릎이 꺾이고 넘어집니다. Space를 누른 시간으로 발사, ←/→로 위치 조절.
- /game/drive/ : 화면을 아래로 당겼다 놓아 출발합니다. 힘 퍼센트·막대는 표시하지 않습니다. 출발 후 브레이크가 없습니다. 차종·노면·구배가 다른 스테이지 5개입니다.
- /game/beer/ : 누르는 동안 따르고 놓으면 멈춥니다. 좌우로 잔을 기울여 거품을 조절합니다. 세 손님의 주문을 완성하세요. Space 따르기, ←/→ 기울기, Enter 제출.

맥주 넘침 감점은 5mL당 1점으로 계속 누적됩니다. 감점 상한은 없고 최종 점수는 최소 0점입니다. 잔에 붙어 흐르는 거품과 맥주, 떨어지는 방울, 젖은 자국과 파문을 표시합니다.

## 파스타와 공통 언어 선택

- `/game/pasta/`: 토마토·크림·바질 페스토·로제 중 소스를 고르면 세 단계 요리가 이어집니다. 단계마다 조작이 다릅니다.
  1. 재료 썰기: 재료가 칼 아래로 지나갑니다. 노란 점선이 칼날에 닿을 때 탭하면 그 두께로 잘립니다. 실제 단면(토마토 씨방, 양파 링, 버섯 T자, 베이컨 지방층, 바질 시포나드)이 있는 조각이 쓰러져 겹쳐 쌓입니다.
  2. 두 화구 동시에: 팬과 냄비가 한 화면에서 같이 끓습니다. 팬을 누르고 있으면 불이 세지고 떼면 약해집니다(온도는 늦게 따라오고 초록 구간은 계속 움직임). 그사이 냄비 거품이 차오르면 팬에서 손을 떼고 냄비를 쳐야 합니다. 면이 알 덴테(약 11~13초)가 되면 냄비에서 팬으로 끌거나 건지기를 누릅니다. 플람베는 면이 익기 전(8.8초)에 옵니다.
  3. 만테카레: 면이 팬으로 쏟아집니다. 면 40가닥은 로프 물리(Verlet)로 계산되어 휘어지고 엉키며 소스 위로 출렁 떠올랐다 떨어집니다. 위로 끌었다 놓으면 끈 길이만큼 높이 뜨고(높을수록 오래 체공), 노란 링 높이에 맞춰 세 번 토스합니다. 끄는 동안 좌우로 흔들면 팬이 돌아 면이 휘감깁니다.
- 판마다 손님(회사원·할머니·꼬마·미식가·대학생) 한 명이 소스와 부탁 하나를 주문합니다. 주문한 소스로 만들고 부탁(꼬들꼬들한 면, 고른 칼질, 토스 묘기, 플람베, 8연속 PERFECT)까지 들어주면 +6점과 팁, 다른 소스는 −5점입니다.
- PERFECT 5연속이면 피버(칼이 빛나고 재료가 12% 빨라짐), 불 조절 중 와인이 들어가는 순간 누르고 있으면 플람베(+10), 토스 3연속 PERFECT는 BRAVISSIMO 연출이 나옵니다.
- 결과 접시에는 직접 썬 조각, 면 익힘 색, 탄 정도, 넘친 소스 자국이 그대로 나타납니다. 점수는 칼질 30% · 불 조절 25% · 면 익힘 30% · 토스 15%입니다.
- 키보드: Space(썰기·팬 불·토스 힘 모으기), S(냄비 치기), Enter(시작·건지기), Esc(일시 정지).
- 모든 게임 상단에 한국어·영어·일본어·번체 중국어·스페인어 선택이 있으며 (스페인어 열은 `i18n-es.js`, 행 수는 `i18n.test.mjs`가 확인) 설정은 브라우저에 저장됩니다. 진행 중 언어를 바꿔도 게임은 유지됩니다.
- `npm test`는 파스타를 포함한 엔진 검사, `npm run test:pasta`는 headless 브라우저에서 실제 마우스·키보드로 한 끼를 완성하는 검사입니다.

## 달고나 뽑기

- `/game/dalgona/`: 하트(★)·꽃(★★)·곰돌이(★★★)·별(★★★★) 중 모양을 고릅니다. **바로 뽑기**는 노점에서 잘 만든 달고나를 받아 곧장 바늘을 들고, **직접 만들기**는 아래 1~3단계부터 합니다.
  1. 설탕 녹이기: 누르고 있으면 국자가 연탄불에 올라가고, 누른 채 빙글빙글 저어야 고르게 녹습니다. 황금빛 구간에서 손을 뗍니다. 젓지 않으면 눌어붙고, 오래 두면 탑니다.
  2. 소다 넣기: 탭해서 소다를 넣고 빠르게 저어 부풀립니다.
  3. 누르기: 누르개를 아래로 끌어 두께를 정하고 놓으면 모양 틀이 찍힙니다.
  4. 모양 뽑기: 선 근처(홈에서 0.12 이내)를 누르면 바늘이 홈에 붙고, 누른 채 문질러 홈을 팝니다. 닿는 순간 소리·진동·물결이 나고, 바늘 끝 고리가 홈 위면 금색·안쪽이면 빨간색, 방금 긁은 곳은 금빛으로 빛납니다. 한 구간이 다 파이면 바깥 조각이 헐거워져 살짝 들썩이고, 손가락으로 휙 밀면 그 방향으로 날아갑니다(지나가는 헐거운 조각도 같이 쓸림). 터치에서는 바늘 끝이 손가락보다 화면 높이의 14%(56~84px) 위에 오고, 바늘이 손가락 쪽으로 기울어 손가락이 바늘 머리를 잡은 모양이 됩니다. 아직 덜 판 바깥쪽을 톡 치면 홈 깊이에 따라 깨끗이 부러지거나(최소 깊이 0.75 이상), 모양 조각까지 같이 떨어지거나(금 1개), 너무 얕으면(평균 0.4 미만) 꿈쩍하지 않습니다. 모든 조각이 헐거워지면 시계가 멈추고 4초 안에 남은 조각을 치우면 되며, 그 뒤엔 저절로 떨어집니다. 한 구간(12개)이 다 파이면 바깥 조각이 떨어집니다. 모양마다 안전 속도가 있고, 너무 빠르거나 모양 안쪽을 긁으면 금 위험이 오릅니다. 금이 모양 안으로 세 번 들어가면 깨집니다. 시간이 지날수록 굳어 잘 깨지고, 침 바르기(3회)로 잠깐 부드럽게 할 수 있습니다.
- 만들기 결과(색·부풂·두께)가 달고나의 깨짐 정도와 긁히는 속도를 정합니다. 점수는 성공 시 온전함 75% + 남은 시간 25%, 80점 이상이면 "하나 더!"입니다.
- 키보드: Space 길게(녹이기·젓기·누르기), L(침 바르기), Q(바로 뽑기), Esc(일시 정지). 모양 뽑기는 마우스·터치 전용이며, 터치에서는 손가락에 가리지 않게 바늘을 조금 위에 둡니다.
- `npm test`에 달고나 엔진 검사가 포함되고, `npm run test:dalgona`는 headless 브라우저에서 실제 마우스로 만들기부터 하트 뽑기까지 완주하고 5개 언어·배치를 검사합니다.
