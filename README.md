# 쑨플레이 3D

의자 컬링과 치킨 드라이브. Three.js의 실제 3D 모델·원근 카메라·조명·그림자를 사용합니다.

- 배포: https://ssunplay-arcade.vercel.app/
- 게임: `/game/curling/`, `/game/drive/`
- 분석: [reverse-engineering.md](reverse-engineering.md)
- 검증: [verification.md](verification.md)

## 실행

Node.js 24에서 `npm install`, `npm run build`, `npm run dev`를 실행합니다. 개발 서버는 http://localhost:4173 입니다.

`npm test`는 상태 전환, 성공·실패와 물리 차등 검사를 실행합니다. `npm run check`는 문법 검사입니다. 브라우저 검사는 `npx playwright install chromium` 후 서버를 켜고 `npm run test:browser`를 실행합니다. `BASE_URL`로 다른 배포를 지정할 수 있습니다.

## 조작

의자 컬링은 주황색 의자를 잡아 위치를 맞추고 앞으로 빠르게 밀어 놓습니다. 마지막 스와이프 속도가 의자의 속도가 됩니다. 너무 빠르면 동료가 넘어집니다. 성공할 때마다 다음 거리로 진행합니다.

치킨 드라이브는 화면을 아래로 당겼다 놓습니다. 출발 후 브레이크가 없습니다. 5개 스테이지에서 차종·노면·구배에 따라 바퀴 접촉과 무게중심이 달라집니다. 절벽까지 남은 거리가 작을수록 좋고, 차체가 걸친 음수 거리도 버티면 인정합니다.

키보드는 Space를 누르는 시간으로 힘을 조절합니다. 컬링에서 ←/→로 의자를 옮깁니다. R 재시작, Esc 일시 정지입니다.

## 파일

`engine.js`는 렌더링과 독립된 물리·상태, `models.js`는 새로 제작한 3D 메시, `stage.js`는 사무실·도로·카메라, `app.js`는 입력·화면·개인 기록입니다. `build.mjs`가 배포용 `dist`를 생성합니다. `scene.js`는 새 3D 장면을 내보내는 호환 모듈입니다. 이전 Canvas 2D 게임 렌더러는 교체했습니다.

## 범위

헤도로봄의 공개 클라이언트를 REA로 관찰하고, 조작과 물리 수치를 분석하여 재구현했습니다. 원본 코드·번들을 게임에 포함하거나 원본 서버에 기록을 제출하지 않습니다. 원본의 저작물·상표 소유권은 원저작자에게 있습니다. 모델은 원본과 유사한 구성을 새로 만든 절차적 메시입니다.

개인 기록·이름·음소거 설정은 브라우저에 저장합니다. 내보내기/가져오기로 최고 기록을 옮길 수 있습니다. 글로벌 랭킹, 계정 로그인·서버 동기화, 원본의 다국어·광고·유료 기능은 구현하지 않았습니다. 컬링 관절 애니메이션과 세부 흔들림은 독립 구현이며 원본과 수치 동일성을 주장하지 않습니다. 자동차의 수치 검증 범위와 REA의 한계는 검증 문서에 명시했습니다.
